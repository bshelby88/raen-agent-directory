Contract Eye — Contract risk review per call, pay-per-call via x402

Built for legal-ops and contract-automation builders: if you run an n8n / Zapier / Make flow that ingests vendor contracts, MSAs, or SaaS agreements, this is a drop-in risk-screen step. POST any contract text (50–50,000 chars) and get back a risk score, flagged one-sided or unusual clauses with severity, explanations, and suggested modifications — settled in USDC on Base via the x402 protocol. No account, no API key, no subscription. Your agent pays $0.05 per call from its wallet and gets the analysis in the same request.

  • Live endpoint: POST https://contract-eye-x402.fly.dev/api/analyze-contract (alias: POST /contract/analyze)
  • Price: $0.05 USDC (Base mainnet, eip155:8453) per call — verified live from the served x402 challenge
  • Discovery: listed on x402scan (ownership-verified); manifest at /.well-known/x402.json

Quick start (agent, 3 steps)

  1. Call the endpoint without payment. You get a 402 Payment Required with a PAYMENT-REQUIRED header describing exactly what to pay (scheme: exact, network: eip155:8453, amount: 50000).
  2. Sign a USDC transferWithAuthorization (EIP-3009) for $0.05 to the payTo in the challenge, attach it as PAYMENT-SIGNATURE.
  3. Re-send the same request. You get 200 with the analysis and an X-Payment-Response settlement receipt.

Any x402 client does this automatically. With agentcash:

npx agentcash@latest fetch https://contract-eye-x402.fly.dev/api/analyze-contract \
  -m POST -b '{"text":"...your contract text (50-50000 chars)...","focus":["liability","termination"]}'

Input

{ "text": "contract text, 50-50000 chars", "focus": ["liability","payment terms"] }

focus is optional — an array of clause areas to prioritize.

Output

A risk score, flagged clauses (each with severity, explanation, and a suggested modification), and a summary of safe clauses. Response fields method and delivery_mode disclose how the analysis was produced.

Honest caveats

  • OUTPUT QUALITY: if LLM analysis is unavailable, the response is a deterministic rule-based clause scan (method + delivery_mode fields disclose this) — pattern-based flagging, not model review.
  • This is an automated first-pass screen, not legal advice. Do not sign anything based on it alone.
  • Text must be 50–50,000 characters; shorter inputs are rejected.
