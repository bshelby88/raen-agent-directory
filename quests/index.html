Quest 1 — Decode a live 402 challenge EASY · 10 XP

Hit a paid endpoint without paying. The server answers HTTP 402 with a base64-encoded challenge header. Decode it and read the real price and payTo address.

curl -s -D headers.txt -o body.txt -X POST \
  https://sentry-forge-x402.fly.dev/scan \
  -H 'Content-Type: application/json' \
  -d '{"target":"example.com"}'

# headers.txt contains: payment-required: 
echo "" | base64 -d | python -m json.tool

Prove it: send us the decoded accepts[0].payTo and maxAmountRequired. (Hint: payTo ends in ...f72f.)
