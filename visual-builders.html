Paid tools for Dify, Flowise & Langflow (visual agent builders)

You built an agent or workflow in a visual builder. It needs tools that do real work — statute citations, contract risk scans, dispute letters, images, document summaries. RAEN is a fleet of 12 production x402 micropayment services on Base Mainnet: every endpoint is pay-per-call USDC, $0.01–$5.00, no subscription, no API-key wall. This page shows the two honest ways to wire them into Dify, Flowise, or Langflow.

Protocol reality first. x402 payments are EIP-3009 signed transfers — a wallet signature. Visual builders have no wallet, so a bare HTTP Request node cannot settle a 402 challenge on its own. You have two workable paths, both below: (A) the RAEN MCP gateway with a self-serve Bearer dev key (no wallet needed on the platform — recommended), or (B) the raw two-POST x402 flow from a Python code node running the official x402 client with your own wallet key.

Path A (recommended): RAEN MCP gateway + Bearer dev key

The gateway exposes 5 flagship tools over Streamable-HTTP MCP — law lookup, ticker analysis, dispute letter, image generation, contract analysis — with free first call on each tool (charge-and-rebate on-chain: you pay the challenge, we rebate the full amount right after settlement, net $0, once per wallet per 30 days). All three platforms can consume an MCP server:

  • Dify — add the gateway as an MCP server (Streamable HTTP) in your workspace's Tools section, with header Authorization: Bearer YOUR_KEY. The tools appear as callable tools for any agent app.
  • Flowise — use the MCP tool node pointing at https://raen-mcp-gateway.fly.dev/mcp with the same authorization header.
  • Langflow — drop in the MCP Tools component, add the gateway URL and the Authorization header, then wire the tools into your agent.

Get the key (self-serve, ~3 minutes, no account):

curl -X POST https://raen-mcp-gateway.fly.dev/keys/request \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com"}'

You get a verification email; your 30-day Bearer key is issued after you click it. Rate limit 3 requests/day/IP. Per-call pricing after the free first call: law lookup $0.05 · ticker $0.05 · dispute letter $0.75 · image gen $0.01 · contract analysis $0.05, settled on-chain in USDC on Base.

Path B: raw x402 two-POST flow from a Python code node

If you want direct x402 (any endpoint, not just the gateway's 5), run a Python code node / custom tool in your builder with the official x402 Python client and your own wallet key. The flow for any endpoint in the table:

  1. POST the endpoint with your JSON body → HTTP 402 with a payment-required header (the challenge: amount, asset, payTo, timeout).
  2. Have the client sign the EIP-3009 transfer for the quoted amount and POST again with the x-payment header → 200 with your result.

Copy-paste recipes live in the x402 Integration Cookbook — recipes/02-python-client.md is exactly this two-POST flow with the signing client. Watch it happen with zero code in the live 402 playground.
