Paid API tools for Agno agents (x402 · Base USDC)

Agno (formerly Phidata) agents pay per call for real work — no API keys, no signups, no monthly plans. Every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol: a request without payment gets a 402 challenge; you sign the challenge (EIP-3005 transferWithAuthorization) with your wallet and re-send with a PAYMENT-SIGNATURE header.

Two-POST payment flow (same for every endpoint)

import json, httpx

def x402_call(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact scheme challenge with your Base wallet (EIP-3005),
    #    then re-send with PAYMENT-SIGNATURE header
    sig = signer.sign_challenge(challenge)
    r2 = httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig})
    return r2.json()

Any EIP-3005 signer works. Alternative: RAEN's Bearer-gated MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key, email verification), same tools over MCP if you prefer a client over raw HTTP. Agno also ships an agno.tools.mcp MCPTools client that can attach to that gateway directly.

Agno tool wrappers

Agno ≥ 1.x — the @tool decorator from agno.tools turns plain functions into agent-callable tools (or group them in a Toolkit class):

from agno.agent import Agent
from agno.tools import tool
import json

@tool
def contract_analyze(agent, text: str, focus: str = "") -> str:
    """Analyze contract text for risky, one-sided, or unusual clauses.
    Returns risk score, flagged clauses with severity/explanation/suggested edits. $0.05/call."""
    focus_list = [f.strip() for f in focus.split(",") if f.strip()]
    result = x402_call("https://contract-eye-x402.fly.dev/api/analyze-contract",
                       {"text": text, "focus": focus_list})
    return json.dumps(result)  # return JSON strings so the model sees the full payload

agent = Agent(tools=[contract_analyze])
agent.print_response("Analyze this lease for auto-renewal traps: ...", markdown=True)

Wrap the parsed dict in json.dumps before returning — Agno tools serialise return values into the model context, and strings keep large JSON payloads intact.

Agno Team pattern

from agno.agent import Agent
from agno.team import Team

# A router agent with the $0.50 dispatch tool + specialist agents with
# the domain tools. Dispatch returns the exact downstream URL, body and
# price — the specialist executes it through the same x402_call.
router = Agent(tools=[dispatch], name="router")
legal  = Agent(tools=[contract_analyze, law_lookup], name="legal")

team = Team(members=[router, legal])
team.print_response("Check this collection letter for FDCPA violations")
