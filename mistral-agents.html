RAEN · x402 paid APIs on Base

Give your Mistral agent paid tools: remote MCP or wallet-native, per-call priced

Mistral's Agents API runs agents that call remote MCP servers directly from the platform — the fastest no-wallet path to paid tools. Point a type:"mcp" tool at the RAEN gateway with your Bearer dev key and the five flagship tools appear (law citations, ticker analysis, dispute letters, image generation, contract analysis). If your agent runs wallet-native code instead, the raw two-POST x402 flow settles USDC on Base per call — payment IS the auth, no API keys.

Path 1 — remote MCP tool on the Agents API (no wallet on the platform)

from mistralai import Mistral

client = Mistral(api_key=MISTRAL_API_KEY)

agent = client.beta.agents.create(
    name="raen-buyer",
    description="Agent that buys RAEN legal/comms tools per call",
    instructions="Use raen tools for law citations, contract analysis, dispute letters. Each call costs its listed USDC price; the operator is billed via the gateway dev key.",
    tools=[{
        "type": "mcp",
        "server_label": "raen",
        "server_url": "https://raen-mcp-gateway.fly.dev/mcp",
        "headers": {"Authorization": "Bearer " + RAEN_DEV_KEY},  # free 30-day key: POST /keys/request
        "allowed_tools": ["raen_law_lookup", "raen_contract_analysis",
                          "raen_dispute_letter", "raen_image_generate"]
    }]
)

Get the free 30-day dev key by POSTing to https://raen-mcp-gateway.fly.dev/keys/request; keep it in a secret store, never in chat text or repo files. Spend guardrail: the key is the budget — request short-lived keys and let the gateway ledger show per-tool usage.

Path 2 — wallet-native function tool (client executes the two-POST 402 flow)

def raen_law_lookup(query: str) -> dict:
    """US consumer-law citation lookup. Costs $0.05 USDC on Base per call."""
    URL = "https://royal-ruby-x402.fly.dev/api/law-lookup"
    r1 = httpx.post(URL, json={"query": query})          # 1) unpaid POST -> 402 challenge
    accepts = r1.json()["accepts"][0]                    #    scheme exact, eip155:8453, USDC
    sig = sign_x402_payment(accepts,                     # 2) sign transferWithAuthorization
            from_key=os.environ["RAEN_WALLET_KEY"])      #    dedicated, thinly-funded key
    r2 = httpx.post(URL, json={"query": query},          # 3) re-send with PAYMENT-SIGNATURE
                    headers={"PAYMENT-SIGNATURE": sig})
    return r2.json()   # { citations[], statutes[], mode }
# register as {"type": "function"} tool; the client executes and returns the result

Honest caveats

  • All-time fleet revenue to date is small and published (live ledger: settlement-collector.fly.dev/ledger). You would be early.
  • tradingagents endpoints currently return a disclosed synthetic demo payload — do not wire them into money decisions.
  • contract-eye and briefsnap disclose fallback delivery modes per response (method / delivery_mode).
  • The consumer-law endpoint is not legal advice; these are information-only services.
  • Network: Base (eip155:8453), USDC, scheme exact, payTo 0x9b8a…f72f — always verify against the live manifest at call time. MCP tool names/params are version-dependent; check the gateway's tool list at connect time.

Machine buy block — x402 per-call SKUs (Base USDC, eip155:8453, scheme exact)

Payment IS auth. Two-POST flow: (1) POST without payment → HTTP 402 challenge (EIP-3005, EIP-3009 transferWithAuthorization); (2) re-send the same POST with the signed quote in the PAYMENT-SIGNATURE header → 200 + result. No API keys, no accounts, per-call USDC settlement on Base. Manifest prices below fetched 2026-11-16.

Payments CORS path / headers: Access-Control-Allow-Origin: * is set on /api/* POST routes (so agent SDKs can cross-origin fetch the paid endpoints); the client must also send PAYMENT-SIGNATURE (EIP-3005/EIP-3009 signed quote) — the header is required, not optional.
