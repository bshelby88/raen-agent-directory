Connect in 3 steps

Step 1 — get a dev key. One POST, no account: 
curl -X POST https://raen-mcp-gateway.fly.dev/keys/request \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com"}'
You'll receive a verification link by email; your 30-day Bearer key is issued after you click it. Rate limit: 3 requests/day/IP.
Step 2 — point your MCP client at the gateway. Claude Desktop (claude_desktop_config.json): 
{
  "mcpServers": {
    "raen": {
      "command": "npx",
      "args": ["-y", "mcp-remote",
               "https://raen-mcp-gateway.fly.dev/mcp",
               "--header", "Authorization: Bearer YOUR_KEY"]
    }
  }
}
Cursor / any Streamable-HTTP client: same URL https://raen-mcp-gateway.fly.dev/mcp with Authorization: Bearer YOUR_KEY.
Step 3 — first call is free. Invoke any tool from your client. Each tool's first call runs the free-first-call flow (charge-and-rebate on-chain via x402 on Base — you pay USDC and are rebated the same amount the first time). After that, per-call pricing above, settled on-chain in USDC.
