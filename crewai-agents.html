Wrapping one as a CrewAI tool

x402 is a two-POST flow: the first POST returns 402 with a payment-required header (a challenge naming price, payee, and network); your wallet signs a USDC transferWithAuthorization on Base and you re-send with a PAYMENT-SIGNATURE header. The x402 python SDK handles the signing; you just wrap it as a BaseTool:

from crewai.tools import BaseTool
from pydantic import BaseModel

class ContractInput(BaseModel):
    text: str
    focus: list[str] = []

class ContractRiskTool(BaseTool):
    name: str = "analyze_contract"
    description: str = ("Analyze contract text for risky or one-sided clauses. "
                        "Returns risk score, flagged clauses with severity and suggested edits. "
                        "Costs $0.05 USDC per call.")
    args_schema: type = ContractInput

    def _run(self, text: str, focus: list[str] = []) -> dict:
        # 1) First POST — read the 402 challenge
        r = httpx.post(URL, json={"text": text, "focus": focus})
        if r.status_code != 402:
            return {"error": "unexpected status", "status": r.status_code}
        challenge = json.loads(base64.b64decode(r.headers["payment-required"]))
        accepts = challenge["accepts"][0]   # scheme exact, eip155:8453, USDC

        # 2) Sign the USDC transferWithAuthorization (x402 SDK or your signer)
        sig = sign_x402_payment(accepts, from_key=AGENT_KEY)

        # 3) Re-send with PAYMENT-SIGNATURE
        r2 = httpx.post(URL, json={"text": text, "focus": focus},
                        headers={"PAYMENT-SIGNATURE": sig})
        return r2.json()   # { risk_score, flagged_clauses[], suggested_edits }

Assign the tool to the crew member that needs it and the crew only spends when the task actually warrants $0.05 — every payment is an on-chain USDC transfer you can reconcile. The same endpoints also work from an MCP bearer-key gateway if you prefer key-auth to wallet-auth, and from LangChain/LangGraph or Haystack, Semantic Kernel and n8n with the identical URLs.

Why pay-per-call beats a key/subscription for crew tools

  • Spend follows use: a 100-call run costs ~$5 on the micro-priced endpoints; an idle month costs $0.
  • No credential sprawl: no per-vendor API keys to store, rotate, or leak in your agents' env.
  • On-chain audit trail: every tool call that cost money left a USDC transfer on Base.
  • Works for humans and agents alike: the identical URL serves a CrewAI tool, an n8n HTTP node, or an autonomous agent with an x402 wallet.

Honest caveats

  • All-time fleet revenue to date: $0.10 internal test settlements; 0 external payers so far (live ledger: settlement-collector.fly.dev/ledger). You would be early.
  • Market-analysis endpoints currently return a disclosed synthetic demo payload — do not wire them into money decisions.
  • contract-eye discloses its delivery mode per response: if LLM analysis is unavailable it returns a deterministic rule-based clause scan (fields method / delivery_mode tell you which). briefsnap discloses fallback mode the same way (mode / delivery_mode).
  • The consumer-law endpoint is not legal advice; these are information-only services.
  • Network: Base (eip155:8453), USDC, scheme exact, payTo 0x9b8a…f72f — always verify against the live manifest at call time.
