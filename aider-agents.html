Paid API tools for Aider (x402 · Base USDC)

Aider — the terminal AI pair programmer — has no native MCP client and no wallet, but it runs shell commands (/run) and writes code in your repo better than almost anything else. That makes it a perfect host for paid x402 tools: drop a thin helper script into the repo and aider will call it, debug it, and extend it like any other project file. Payment is either a Bearer dev key (Path 1, recommended) or a wallet script the pair signs with (Path 2). Everything below accepts USDC on Base via the x402 HTTP-native payment protocol.

Path 1 (recommended): a raen_client.py helper aider runs and maintains

First get a free 30-day dev key for the RAEN MCP-style gateway rail (the gateway settles per call; the key is the billing rail):

curl -X POST https://raen-mcp-gateway.fly.dev/keys/request \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com"}'
# → check your inbox for the verification link + key

Then add a ~40-line helper to your repo (aider will happily write it for you if you paste this spec into the chat):

# raen_client.py — call RAEN paid endpoints via the MCP gateway
import json, os, urllib.request

KEY = os.environ["RAEN_KEY"]          # export RAEN_KEY=... (30-day dev key)
BASE = "https://raen-mcp-gateway.fly.dev/mcp"

def call(tool: str, args: dict) -> dict:
    req = urllib.request.Request(BASE, method="POST",
        data=json.dumps({"jsonrpc":"2.0","id":1,"method":"tools/call",
                         "params":{"name":tool,"arguments":args}}).encode(),
        headers={"Content-Type":"application/json",
                 "Authorization":f"Bearer {KEY}",
                 "Accept":"application/json, text/event-stream"})
    return json.load(urllib.request.urlopen(req, timeout=120))

if __name__ == "__main__":
    import sys
    print(json.dumps(call(sys.argv[1], json.loads(sys.argv[2])), indent=2)[:4000])

Run it like any project script:

/run python raen_client.py raen_law_lookup '{"topic":"debt validation"}'

The five gateway tools: raen_law_lookup ($0.05), raen_ticker_analysis ($0.05, synthetic demo — see caveats), raen_dispute_letter ($0.10), raen_image_generate ($0.01), raen_contract_analysis ($0.05). Keep the key out of git: add RAEN_KEY to .env / your shell profile, never to the repo.

Path 2 (wallet-native): the two-POST x402 flow via /run

For wallet-native calls (no gateway key, direct to the services), hand aider the cookbook recipe 02 pattern — a minimal Python signer with web3.py is ~30 lines and aider can write it verbatim:

POST https://royal-ruby-x402.fly.dev/api/law-lookup   (no payment header)
← 402 + payment-required header (base64 JSON challenge: amount, payTo, asset)
# sign USDC transferWithAuthorization (EIP-3009) for that exact amount
POST same URL + x-payment header (base64 signed JSON)
← 200 + result body + x-payment-response (settlement tx on Base)

Aider-specific conversion details:

  • Load the wallet key as an env var (export RAEN_WALLET_KEY=...) — never let aider commit a key; keep wallet files in .gitignore.
  • Put a spend guardrail in CONVENTIONS.md (read every session): e.g. "never sign an x402 challenge above $1.00 without asking me first". Aider follows conventions reliably.
  • Aider's diff-based workflow means the signer script is reviewable before it ever runs — every payment path lands in a visible edit.

Dispatch-first pattern (cheapest way to explore)

If you don't know which service you need, call dispatch ($0.50) with the intent; it routes to the right endpoint and tells you the cost before you spend more.

Why this works well specifically in Aider

  • Aider already lives in your terminal with your venv — the helper script and signer are ordinary project files it can run, test, and iterate on.
  • CONVENTIONS.md is a plain-text spend guardrail read every session — the cheapest possible budget control.
  • Per-call micro-prices mean a full research or dispute task costs cents — no subscription, no key-of-ours.

Verify before you pay (checklist)

  • Discovery: GET /.well-known/x402.json on any service — machine-readable price + payTo.
  • A2A agent card: raen-mcp-gateway.fly.dev/.well-known/agent.json.
  • Public settlement ledger: settlement-collector.fly.dev/ledger.
  • More x402 recipes: x402-cookbook (curl 402-decode, Python client, free-first-call, MCP gateway).
