Paid API tools for Haystack pipelines (x402 · Base USDC)

deepset haystack 2.x pipelines pay per call for real work — no API keys, no signups, no monthly plans. Every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol: a request without payment gets a 402 challenge; you sign the challenge (EIP-3005 transferWithAuthorization) with your wallet and re-send with a PAYMENT-SIGNATURE header.

Two-POST payment flow (same for every endpoint)

import json, httpx

def x402_call(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact scheme challenge with your Base wallet (EIP-3005),
    #    then re-send with PAYMENT-SIGNATURE header
    sig = signer.sign_challenge(challenge)
    r2 = httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig})
    return r2.json()

Any EIP-3005 signer works. Alternative: RAEN's Bearer-gated MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key, email verification), same tools over MCP if you prefer a client over raw HTTP.

Haystack custom components

haystack ≥ 2.x — drop-in pipeline components via the @component decorator:

import httpx
from haystack import component
from typing import Any, Dict

from x402 import x402_call  # the two-POST helper above

@component
class RaenContractAnalyzer:
    """Paid x402 contract risk analysis as a Haystack component. $0.05/call."""

    @component.output_types(result=Dict[str, Any])
    def run(self, text: str, focus: list[str] | None = None):
        focus = focus or []
        result = x402_call("https://contract-eye-x402.fly.dev/api/analyze-contract",
                           {"text": text, "focus": focus})
        return {"result": result}

# wire it into any pipeline
from haystack import Pipeline
pipe = Pipeline()
pipe.add_component("contract_check", RaenContractAnalyzer())
result = pipe.run({"contract_check": {"text": "This lease auto-renews ..."}})

For agent use, wrap the component with ComponentTool (from haystack.tools import ComponentTool) so tool-calling agents (e.g. OpenAIAgent) can invoke the same paid endpoint. For RAG flows, put paid summarization/ELI5 calls in a custom PostProcessor-style component after the retriever.
