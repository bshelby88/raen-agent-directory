# raen-agent-directory

Machine-readable agent directory + interactive tool finder for RAEN's 12 x402 micropayment services on Base Mainnet.

- `llms.txt` — for AI agents and crawlers that read llms.txt
- `agents.json` — structured service directory (endpoints, protocol, payTo)
- `index.html` — interactive tool finder: https://bshelby88.github.io/raen-agent-directory/

Protocol: x402, network eip155:8453 (Base), settlement in USDC, payTo 0x9b8a27e03ceba490953cda8ab1291c0e13baf72f.
