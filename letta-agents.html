Paid API tools for Letta agents (x402 · Base USDC)

Letta (formerly MemGPT — letta / letta-client, the memory-tiered agent framework) agents can pay per call for real work — no API keys, no signups, no monthly plans. Every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol: a request without payment gets a 402 challenge; you sign the challenge (EIP-3009 transferWithAuthorization) with your wallet and re-send with a PAYMENT-SIGNATURE header.

Path 1 — custom Python tool (two-POST 402 flow)

import json, requests

def x402_call(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = requests.post(url, json=body, timeout=60)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact-scheme challenge with your Base wallet (EIP-3009
    #    transferWithAuthorization), then re-send with the payment header
    sig = signer.sign_challenge(challenge)
    r2 = requests.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig}, timeout=120)
    return r2.json()

Any EIP-3009 signer works. Register the wrapper as a Letta custom tool: client.tools.upsert_from_function(func=law_lookup, ...) (Python SDK) or paste the source into the Letta ADE tool editor — Letta stores the tool and your agent calls it like any other.

Why Letta + x402

Letta agents persist memory across sessions and run indefinitely — exactly the shape where per-call micropayments beat API keys: a long-running personal agent can pay $0.05 for a law citation and $1.00 for a document summary with no billing relationship, no card, and no rate-limit account. The 402 → sign → re-send loop lives entirely inside a tool, so the core agent never sees payment machinery; with the MCP gateway path the agent doesn't even see the tool wrapper.

Cost control for memory-driven agents

Start every paid tool with a spend guardrail — Letta tool source is just Python, so enforce a per-run cap inside the wrapper:

_SPENT = {"usd": 0.0}
BUDGET_USD = 1.00  # per-process cap; Letta re-imports tools on edit

PRICE = {"https://briefsnap-x402.fly.dev/api/summarize": 1.00, ...}

def x402_call(url, body, signer):
    if _SPENT["usd"] + PRICE.get(url, 0.05) > BUDGET_USD:
        return {"error": "budget exhausted for this run", "spent_usd": _SPENT["usd"]}
    result = x402_call_raw(url, body, signer)
    _SPENT["usd"] += PRICE.get(url, 0.05)
    return result
