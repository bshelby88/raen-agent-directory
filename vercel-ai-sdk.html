Paid API tools for Vercel AI SDK agents (x402 · Base USDC)

ai-SDK (Vercel AI SDK) agents pay per call for real work — no API keys, no signups, no monthly plans. Every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol: a request without payment gets a 402 challenge; you sign the challenge (EIP-3005 transferWithAuthorization) with your wallet and re-send with a PAYMENT-SIGNATURE header.

Two-POST payment flow (same for every endpoint)

import { tool, generateText, stepCountIs } from "ai";
import { z } from "zod";

// x402_call: POST once, decode the 402 challenge, sign with your Base
// wallet (EIP-3005 transferWithAuthorization), re-send with the header.
const x402_call = (url: string, body: unknown, signChallenge: (c: any) => Promise) =>
  fetch(url, { method: "POST", body: JSON.stringify(body),
               headers: { "Content-Type": "application/json" } })
    .then(async (r) => {
      if (r.status !== 402) return r.json();
      const challenge = JSON.parse(r.headers.get("payment-required")!); // accepts[]
      const sig = await signChallenge(challenge);
      return fetch(url, { method: "POST", body: JSON.stringify(body),
        headers: { "Content-Type": "application/json", "PAYMENT-SIGNATURE": sig } })
        .then((r2) => r2.json());
    });

Any EIP-3005 signer works (e.g. viem + a Base wallet). Alternative: RAEN's Bearer-gated MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key, email verification), same tools over MCP, usable via the SDK's MCP client support if you prefer a client over raw HTTP.

AI SDK tool wrappers

ai ≥ 4.0 — tool() with a zod schema works with generateText, streamText and agent loops:

import { openai } from "@ai-sdk/openai";

const contractAnalyze = tool({
  description: "Analyze contract text for risky, one-sided, or unusual clauses. $0.05/call.",
  parameters: z.object({ text: z.string().min(50), focus: z.array(z.string()).optional() }),
  execute: async ({ text, focus }) =>
    x402_call("https://contract-eye-x402.fly.dev/api/analyze-contract",
              { text, focus: focus ?? [] }, signChallenge),
});

const result = await generateText({
  model: openai("gpt-4o-mini"),
  tools: { contractAnalyze },
  stopWhen: stepCountIs(5),
  prompt: "Analyze this lease for auto-renewal traps: ...",
});

Because the tools are priced per call, gate them behind agent-choice: the description carries the price so the model only spends when the task warrants it. Cap spend with stopWhen step limits or by exposing only the dispatch tool (below) and letting it return the exact downstream call for a human/agent confirm step.

Router-agent pattern

// Expose only the $0.50 dispatch tool to the model; it returns the exact
// downstream URL, body and price. Then either execute it with x402_call
// in the same loop or surface it for confirmation before spending.
const dispatch = tool({
  description: "Route a natural-language request to the right RAEN paid service. Returns url, body and price.",
  parameters: z.object({ intent: z.string() }),
  execute: ({ intent }) =>
    x402_call("https://dispatch-x402.fly.dev/dispatch", { intent }, signChallenge),
});
