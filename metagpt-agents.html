Paid API tools for MetaGPT roles (x402 · Base USDC)

MetaGPT (DeepWisdom) roles run Action classes per step — a paid API is just an Action whose run settles USDC on Base via the x402 HTTP-native payment protocol: unpaid request gets a 402 challenge; sign it (EIP-3009 transferWithAuthorization) and re-send with a X-PAYMENT header. No API keys, no signups, no monthly plans.

Two-POST payment flow (same for every endpoint)

import json, httpx

def x402_call(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact scheme challenge with your Base wallet (EIP-3005),
    #    then re-send with X-PAYMENT header
    sig = signer.sign_challenge(challenge)
    r2 = httpx.post(url, json=body, headers={"X-PAYMENT": sig})
    return r2.json()

Any EIP-3005 signer works. Alternative: RAEN's x402-paid MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key), same tools over MCP if you prefer a client over raw HTTP.

MetaGPT Action wrapper (async, software-company pattern)

Drop this Action into any Role. The example turns a review step into a paid $0.05 risk analysis; the same pattern wraps every endpoint in the catalog below.

import json
from metagpt.actions import Action

class RaenContractAnalysis(Action):
    """Paid x402 contract risk analysis ($0.05/call, USDC on Base)."""

    async def run(self, contract_text: str, instructions: str = "") -> str:
        url = "https://contract-eye-x402.fly.dev/api/analyze-contract"
        body = {"text": contract_text, "focus": [instructions] if instructions else []}
        r = await client.post(url, json=body)          # 1) trigger the 402 challenge
        if r.status_code != 402:
            return r.text
        challenge = json.loads(r.headers["payment-required"])
        sig = wallet.sign_x402_challenge(challenge)    # 2) EIP-3009 sign (x402 SDK / web3.py)
        r2 = await client.post(url, json=body, headers={"X-PAYMENT": sig})
        return r2.text

# wire into a role:  self.set_actions([RaenContractAnalysis])

Spend guardrail for multi-agent runs: MetaGPT teams fire Actions in loops — keep the wallet key in an env var, fund a dedicated thin wallet per run, and add a per-run budget check inside the Action (check balance before signing; refuse below your floor).
