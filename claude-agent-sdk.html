Paid API tools for the Claude Agent SDK (x402 · Base USDC)

The Claude Agent SDK (@anthropic-ai/claude-agent-sdk for TypeScript, claude-agent-sdk for Python) runs agentic loops over MCP tools — and MCP tools can pay per call for real work. No API keys, no signups, no monthly plans: every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol. A request without payment gets a 402 challenge; you sign it (EIP-3005 transferWithAuthorization) with a Base wallet and re-send with a PAYMENT-SIGNATURE header.

Two-POST payment flow (same for every endpoint)

import json, httpx

def x402_post(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact scheme challenge with your Base wallet (EIP-3005),
    #    then re-send with PAYMENT-SIGNATURE header
    sig = signer.sign_challenge(challenge)
    r2 = httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig})
    return r2.json()

Any EIP-3005 signer works. Alternative: RAEN's Bearer-gated MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key, email verification), same tools over MCP, which plugs straight into the SDK's native MCP support (AllowedMcpServer / mcp_servers) if you prefer a gateway over raw HTTP.

Python: expose the paid call as an SDK tool

import json, httpx
from claude_agent_sdk import tool, create_sdk_mcp_server, query

def _x402_call(url: str, body: dict, signer) -> dict:
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])
    sig = signer.sign_challenge(challenge)
    return httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig}).json()

@tool("contract_analyze", "Analyze contract text for risky or one-sided clauses. $0.05/call",
      {"text": str, "focus": list[str] | None})

    return _x402_call("https://contract-eye-x402.fly.dev/api/analyze-contract",
                      {"text": args["text"], "focus": args.get("focus") or []})

server = create_sdk_mcp_server("raen_paid", tools=[contract_analyze])

const x402Call = async (url: string, body: unknown, sign: (c: unknown) => string) => {
  const first = await fetch(url, { method: "POST", body: JSON.stringify(body) });
  if (first.status !== 402) return first.json();
  const challenge = JSON.parse(first.headers.get("payment-required")!);
  const second = await fetch(url, {
    method: "POST",
    headers: { "PAYMENT-SIGNATURE": sign(challenge), "content-type": "application/json" },
    body: JSON.stringify(body),
  });
  return second.json();
};

Why Claude Agent SDK + x402

The SDK's tool loop is exactly where per-call micropayments beat API keys: a subagent can pay $0.05 for a law citation and $1.00 for a document summary mid-task with no billing relationship, no provisioning, and no human. Because each tool call is an independent HTTP request, the 402 → sign → re-send loop composes with subagents, hooks, and permission modes without touching any of them.
