Paid API tools for OpenAI Codex CLI (x402 · Base USDC)

Codex CLI — OpenAI's open-source terminal coding agent — executes shell commands natively, which makes it a natural x402 payer: it can hold a wallet, receive a 402 challenge, sign the EIP-3009 authorization, and retry with payment, all inside the sandbox it already runs. If you'd rather not give it a wallet, the second path needs no signing: RAEN's Bearer-gated MCP gateway, where the dev key is the billing rail. Everything below accepts USDC on Base via the x402 HTTP-native payment protocol.

Path 1 (recommended for wallet-native runs): the two-POST x402 flow from a shell step

Codex can run this itself — paste the cookbook recipe 02 pattern into the task. The flow:

POST https://royal-ruby-x402.fly.dev/api/law-lookup   (no payment header)
← 402 + payment-required header (base64 JSON challenge: amount, payTo, asset)
# sign USDC transferWithAuthorization (EIP-3009) for that exact amount with viem
POST same URL + x-payment header (base64 signed JSON)
← 200 + result body + x-payment-response (settlement tx on Base)

Get a Base wallet key into the environment the way your setup allows (env var, secret store) — never hardcode it in a repo file. A minimal Python signer with viem/web3.py is ~30 lines; recipe 02 has it verbatim.

Path 2: the RAEN MCP gateway in config.toml (no wallet in the sandbox)

The gateway exposes 5 tools over streamable HTTP MCP: raen_law_lookup ($0.05), raen_ticker_analysis ($0.05, synthetic demo — see caveats), raen_dispute_letter ($0.10), raen_image_generate ($0.01), raen_contract_analysis ($0.05). The Bearer key gates the whole server and settles per call; get a free 30-day dev key first:

curl -X POST https://raen-mcp-gateway.fly.dev/keys/request \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com"}'
# → check your inbox for the verification link + key

Then register the server in ~/.codex/config.toml:

[mcp_servers.raen]
url = "https://raen-mcp-gateway.fly.dev/mcp"

[mcp_servers.raen.http_headers]
Authorization = "Bearer <your-30-day-dev-key>"

Tools appear as raen__raen_law_lookup etc. in the tool list. Keep the key out of any dotfiles you sync or commit — if your Codex version supports environment expansion for remote-server headers, prefer that. Newer Codex builds also accept codex mcp add; codex mcp list confirms registration.

Dispatch-first pattern (cheapest way to explore)

If you don't know which service you need, call dispatch ($0.50) with the intent; it routes to the right endpoint and tells you the cost before you spend more.

Why this works well specifically in Codex

  • Codex already executes bash/python — the two-POST flow is just another script it can run, inspect, and debug autonomously.
  • Approval prompts give you a natural spend-control point: review the curl/script before it signs.
  • Per-call micro-prices mean a full research or dispute task costs cents — no subscription, no key-of-ours.

Verify before you pay (agent checklist)

  • Discovery: GET /.well-known/x402.json on any service — machine-readable price + payTo.
  • A2A agent card: raen-mcp-gateway.fly.dev/.well-known/agent.json.
  • Public settlement ledger: settlement-collector.fly.dev/ledger.
  • More x402 recipes: x402-cookbook (curl 402-decode, Python client, free-first-call, MCP gateway).
