Paid API tools for DSPy programs (x402 · Base USDC)

DSPy programs pay per call for real work — no API keys, no signups, no monthly plans. Every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol: a request without payment gets a 402 challenge; you sign the challenge (EIP-3005 transferWithAuthorization) with your wallet and re-send with a PAYMENT-SIGNATURE header.

Two-POST payment flow (same for every endpoint)

import base64, json, requests

def x402_call(url: str, body: dict, signer) -> dict:
    # signer(challenge_dict) -> str : EIP-3005 transferWithAuthorization
    # signature serialized for the PAYMENT-SIGNATURE header
    r = requests.post(url, json=body, timeout=60)          # 1) trigger the challenge
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(base64.b64decode(r.headers["payment-required"]))
    sig = signer(challenge)                                 # 2) sign the exact-scheme
    r2 = requests.post(                                     #    challenge with your
        url, json=body,                                     #    Base wallet, then re-send
        headers={"content-type": "application/json", "PAYMENT-SIGNATURE": sig},
        timeout=120,
    )
    return r2.json()

Any EIP-3005 signer works; the official x402 Python client wraps this exact flow if you'd rather not hand-roll it. DSPy tool wrappers

dspy.Tool(fn) turns any typed, docstringed Python function into a tool DSPy modules can invoke — so wrap each paid endpoint in a plain function and hand the tools to dspy.ReAct:

import dspy

dspy.configure(lm=dspy.LM("openai/gpt-4o-mini"))

def law_lookup(topic: str) -> dict:
    """Paid US consumer-law citation lookup ($0.05/call, Base USDC x402).

    Returns FCRA/FDCPA/TILA/state-UDAP citations with plain-English
    summaries. Not legal advice.
    """
    return x402_call(
        "https://royal-ruby-x402.fly.dev/api/law-lookup",
        {"topic": topic},
        signer,
    )

def analyze_contract(text: str, focus: list[str] | None = None) -> dict:
    """Paid contract risk analysis ($0.05/call, Base USDC x402).

    Returns risk score, flagged clauses with severity/explanation/
    suggested edits.
    """
    body = {"text": text}
    if focus:
        body["focus"] = focus
    return x402_call(
        "https://contract-eye-x402.fly.dev/api/analyze-contract",
        body,
        signer,
    )

raen_tools = [dspy.Tool(law_lookup), dspy.Tool(analyze_contract)]

class ComplianceAnalyst(dspy.Module):
    def __init__(self):
        super().__init__()
        self.react = dspy.ReAct(
            "question -> answer, citations: list[str]",
            tools=raen_tools,
        )

    def forward(self, question: str):
        return self.react(question=question)

result = ComplianceAnalyst()(
    "Does this lease's auto-renewal clause violate any state UDAP rules? "
)

signer builds the transferWithAuthorization EIP-712 message from challenge["accepts"][0] (from, to = payTo, value in USDC base units, validAfter/validBefore, nonce), signs typed data on Base (chain 8453) with any web3 lib (web3.py, eth-account), and serializes to the PAYMENT-SIGNATURE header. Cost-aware pipeline pattern

# DSPy compiles pipelines; a dispatch-first pattern keeps paid-call costs down:
# call the $0.50 dispatch router once, then execute only the recommended
# downstream endpoint through the same x402_call helper.

def route_intent(query: str) -> dict:
    """Paid meta-router ($0.50/call): returns the best-matching RAEN
    service and a ready-to-send request for it."""
    return x402_call("https://dispatch-x402.fly.dev/dispatch",
                     {"query": query}, signer)
