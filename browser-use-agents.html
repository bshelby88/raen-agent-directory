RAEN · x402 paid APIs on Base

Give your browser-use agent a wallet: custom actions that pay per call

browser-use agents drive a real browser and execute your Python controller actions in-process — which means an action can hold a wallet key and settle payment inline, no browser clicks required. The endpoints below are plain HTTPS POSTs costing $0.01–$3.00 per call, settled in USDC on Base via x402. The payment IS the auth: no API keys, no subscriptions. Register the paid action once with @controller.action and the agent buys exactly when its task needs it.

browser-use controller action: the two-POST 402 flow

import os, httpx
from browser_use import Agent, Controller
from browser_use.browser import BrowserSession

controller = Controller(exclude_actions=["done"])

@controller.action("Look up a US consumer-law citation (FCRA/FDCPA/TILA/UDAP). Costs $0.05 USDC per call.")
def raen_law_lookup(query: str) -> str:
    URL = "https://royal-ruby-x402.fly.dev/api/law-lookup"
    r1 = httpx.post(URL, json={"query": query})          # 1) unpaid POST -> 402 challenge
    accepts = r1.json()["accepts"][0]                    #    scheme exact, eip155:8453, USDC
    sig = sign_x402_payment(accepts,                     # 2) sign transferWithAuthorization
            from_key=os.environ["RAEN_WALLET_KEY"])      #    dedicated, thinly-funded key
    r2 = httpx.post(URL, json={"query": query},          # 3) re-send with PAYMENT-SIGNATURE
                    headers={"PAYMENT-SIGNATURE": sig})
    return str(r2.json())   # { citations[], statutes[], mode }

agent = Agent(task="…", llm=llm, controller=controller,
              browser_session=BrowserSession(headless=True))

Spend guardrails that fit browser-use's model: the wallet key lives only in the process env of the runner you control (never in chat text or the task prompt), the key itself is the budget (fund it thinly), and paid actions are named with their price so the LLM decides per call. Every payment is an on-chain USDC transfer you can reconcile. If you'd rather not run a wallet, the same endpoints work through the MCP bearer-key gateway with a 30-day dev key.

Honest caveats

  • All-time fleet revenue to date is small and published (live ledger: settlement-collector.fly.dev/ledger). You would be early.
  • tradingagents endpoints currently return a disclosed synthetic demo payload — do not wire them into money decisions.
  • contract-eye and briefsnap disclose fallback delivery modes per response (method / delivery_mode).
  • The consumer-law endpoint is not legal advice; these are information-only services.
  • Network: Base (eip155:8453), USDC, scheme exact, payTo 0x9b8a…f72f — always verify against the live manifest at call time.
