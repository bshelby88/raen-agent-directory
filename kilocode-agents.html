Path 1 (no wallet — recommended): the RAEN MCP gateway in Kilo Code

The gateway is a Streamable-HTTP MCP server at https://raen-mcp-gateway.fly.dev/mcp, Bearer-gated. Get a free 30-day dev key first:

curl -s -X POST https://raen-mcp-gateway.fly.dev/keys/request \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com"}'
# email verification link arrives; the 30-day Bearer key follows

Then add the gateway in Kilo Code's MCP Servers view (Settings → MCP → Edit Project MCP), which writes .kilocode/mcp.json in your project (or Edit Global MCP for all workspaces):

{
  "mcpServers": {
    "raen": {
      "type": "streamable-http",
      "url": "https://raen-mcp-gateway.fly.dev/mcp",
      "headers": { "Authorization": "Bearer YOUR_DEV_KEY" },
      "disabled": false,
      "alwaysAllow": []
    }
  }
}

Tools appear as mcp__raen__raen_law_lookup etc. The gateway's 402-paid gate is what makes the Bearer key the billing rail — Kilo Code itself never pays a 402 challenge, so the gateway settles downstream and meters the calls against your key.

Project-level config overrides global; the global settings file is reachable through the same MCP Servers view. Kilo Code's CLI variant (~/.config/kilo/kilo.json → "mcp": {"raen": {"type":"remote", "url":…, "headers":…}}) uses the same URL and headers.

Path 2 (wallet-native): raw two-POST x402 flow from Kilo's terminal

For endpoints outside the gateway's 5 tools, have Kilo Code run the two-POST x402 flow (EIP-3009 transferWithAuthorization on Base USDC) in its own shell — recipe with a working Python client: cookbook recipe 02.

  1. POST the endpoint → read the payment-required header, base64-decode the accepts[] challenge.
  2. Sign the EIP-3009 authorization with a Base-wallet key and POST again with x-payment → the service settles via the facilitator and returns the result.
Kilo Code spend guardrails (read before wallet work):
  • Never put the paid tools in alwaysAllow — auto-allowed tools run without a confirmation prompt, so each call spends without a checkpoint. Leave alwaysAllow: [] and approve per call.
  • Budget rule in .kilocoderules/ (or project rules) so the agent re-reads a spending cap every session.
  • Wallet key as an environment variable — never a committed file; Kilo edits repo files by default.

Honest caveats

  • tradingagents / staci-tradingagents disclose their demo/simulation payload nature in the live manifest.
  • royal-ruby runs a disclosed wallet-bucket price test; the challenge you receive is the exact price you pay.
  • contract-eye and briefsnap disclose deterministic fallback modes when their LLM is unavailable.
  • Information, not legal or financial advice.
