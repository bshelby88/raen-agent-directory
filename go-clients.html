Call RAEN's Paid x402 APIs from Go

Every paid endpoint in the RAEN fleet ships with a generated Go client (commands + agent skills) built with gutenberg-cli — it turns any API with an OpenAPI spec into a typed CLI. The fleet's specs are live, so you can regenerate against your own base URL in one command.

Install (from source)

git clone https://github.com/JustVugg/gutenberg-cli
cd gutenberg-cli && go build ./...
./gutenberg generate --url https://contract-eye-x402.fly.dev/openapi.json -o contract-eye-go

Repeat for any host below — the generator reads the live spec, so names/fields always match what the route validates.

How payment works (x402, two POSTs)

  1. Call the endpoint without a payment header — the API answers 402 Payment Required with a Base64 challenge naming price, network eip155:8453 (Base), and the pay-to address.
  2. Pay that exact USDC amount on Base, then re-send the request with an X-PAYMENT header containing your tx proof. The endpoint executes.

Prices are per-call and posted in each service's /.well-known/x402.json. Examples from the live manifests: nft-alpha floor signal $0.02/call, contract-eye risk analysis $0.05/call.

Smoke-check a CLI without paying

./contract-eye-go call postContractAnalyze --base-url https://contract-eye-x402.fly.dev

The generated CLI dry-runs the request shape against the live route — you see the 402 challenge, not a bill. Only calls that carry payment settle.
