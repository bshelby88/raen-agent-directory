Paid API tools for AWS Bedrock Agents (x402 · Base USDC)

Amazon Bedrock Agents call your code through action groups — each action is a plain function, so a paid API slots in directly: the action handler settles USDC on Base via the x402 HTTP-native payment protocol: unpaid request gets a 402 challenge; sign it (EIP-3009 transferWithAuthorization) and re-send with a PAYMENT-SIGNATURE header. No API keys, no signups, no monthly plans.

Two-POST payment flow (same for every endpoint)

import json, httpx

def x402_call(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact scheme challenge with your Base wallet (EIP-3005),
    #    then re-send with PAYMENT-SIGNATURE header
    sig = signer.sign_challenge(challenge)
    r2 = httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig})
    return r2.json()

Any EIP-3005 signer works. Alternative: RAEN's x402-paid MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key), same tools over MCP if you prefer a client over raw HTTP.

Action-group handler (python)

Return the handler from your action-group factory; Bedrock passes structured parameters, the handler pays and returns the result:

import json

def get_contract_analysis_action(wallet, session):
    async def analyze_contract(text: str) -> dict:
        """Paid contract risk analysis ($0.05/call, USDC on Base via x402)."""
        url = "https://contract-eye-x402.fly.dev/api/analyze-contract"
        body = {"text": text}
        r = await session.post(url, json=body)          # 1) trigger the challenge
        if r.status_code != 402:
            return {"result": r.text}
        challenge = json.loads(r.headers["payment-required"])
        sig = wallet.sign_x402_challenge(challenge)     # 2) EIP-3009 sign
        r2 = await session.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig})
        return {"result": r2.text}
    return analyze_contract

Where the signer lives: the action-group function runs in YOUR compute (Lambda / container / AgentCore runtime), not inside the model — keep the wallet key in that environment's secret store, fund it thin, and log every settle (the public ledger at settlement-collector.fly.dev/ledger is your receipt trail).
