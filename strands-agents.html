Paid API tools for AWS Strands Agents (x402 · Base USDC)

Strands Agents (strands-agents / strands-agents-tools, Amazon's open-source agent SDK) can pay per call for real work — no API keys, no signups, no monthly plans. Every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol: a request without payment gets a 402 challenge; you sign the challenge (EIP-3005 transferWithAuthorization) with your wallet and re-send with a PAYMENT-SIGNATURE header.

Two-POST payment flow (same for every endpoint)

import json, httpx

def x402_post(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact scheme challenge with your Base wallet (EIP-3005),
    #    then re-send with PAYMENT-SIGNATURE header
    sig = signer.sign_challenge(challenge)
    r2 = httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig})
    return r2.json()

Any EIP-3005 signer works. Alternative: RAEN's Bearer-gated MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key, email verification), same tools over MCP, which plugs straight into a Strands MCPClient if you prefer a client over raw HTTP.

Strands tool wrappers

Expose any endpoint as a Strands tool with the @tool decorator (Python, strands-agents):

import json, httpx
from strands import Agent, tool

def _x402_call(url: str, body: dict, signer) -> dict:
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])
    sig = signer.sign_challenge(challenge)
    return httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig}).json()

@tool
def contract_analyze(text: str, focus: list[str] = []) -> dict:
    """Analyze contract text for risky, one-sided, or unusual clauses.
    Returns risk score, flagged clauses with severity/explanation/suggested edits. $0.05/call."""
    return _x402_call("https://contract-eye-x402.fly.dev/api/analyze-contract",
                      {"text": text, "focus": focus})

agent = Agent(tools=[contract_analyze])
agent("Analyze this lease for auto-renewal traps: ...")

Why Strands + x402

Strands agents are model-agnostic (Bedrock, OpenAI, Anthropic, Ollama) and tool-driven — exactly the shape where per-call micropayments beat API keys: a multi-agent workflow can pay $0.05 for a law citation and $1.00 for a document summary with no billing relationship at all. The 402 → sign → re-send loop lives entirely inside a Python tool, so the model never sees payment machinery.
