NFT Alpha — Real-time OpenSea market signals, pay-per-call via x402

What it is: A paid API that returns 5-minute rolling market signals for watched NFT collections — listings, sales, bids, sell-through, floor pressure, bid frenzy — settled in USDC on Base via the x402 protocol. No account, no API key, no subscription. Your agent pays $0.02 per call from its wallet and gets the data in the same request.

  • Live endpoint: POST https://nft-alpha-x402.fly.dev/api/nft-signal
  • Price: $0.02 USDC (Base mainnet, eip155:8453) per call
  • Discovery: listed on x402scan (ownership-verified); CDP Bazaar indexed

Quick start (agent, 3 steps)

  1. Call the endpoint without payment. You get a 402 Payment Required with a PAYMENT-REQUIRED header describing exactly what to pay.
  2. Sign a USDC transferWithAuthorization (EIP-3009) for $0.02 to the payTo in the challenge, attach it as PAYMENT-SIGNATURE.
  3. Re-send the same request. You get 200 with the signals and an X-Payment-Response settlement receipt.

Any x402 client does this automatically. With agentcash:

npx agentcash@latest fetch https://nft-alpha-x402.fly.dev/api/nft-signal \
  -m POST -b '{"collection":"pudgypenguins"}'

Input

{ "collection": "pudgypenguins" }

or { "collections": ["azuki","milady"] } (batch ≤ 10), or {} for all watched collections.

Watched collections: boredapeyachtclub, mutant-ape-yacht-club, azuki, pudgypenguins, milady, doodles-official, degods, cryptopunks.

Output (per collection)

Listing / sale / bid counts over the rolling 5-minute window, price stats (min/max/mean floor & sale), sell-through ratio, and a signal classification:
HIGH_DEMAND · UNDERPRICED_LISTING · BID_FRENZY · DUMP_WARNING · LOW_DEMAND

Honest caveats

  • Data is a 5-minute rolling window from the OpenSea Stream API; quiet collections return sparse/empty windows, not errors.
  • Polling the same collection faster than the window refreshes does not produce independent signals.
  • This is market activity data, not financial advice. No signal guarantees a profitable trade.
