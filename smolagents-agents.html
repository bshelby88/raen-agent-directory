Paid API tools for SmolAgents agents (x402 · Base USDC)

HuggingFace smolagents agents pay per call for real work — no API keys, no signups, no monthly plans. Every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol: a request without payment gets a 402 challenge; you sign the challenge (EIP-3005 transferWithAuthorization) with your wallet and re-send with a PAYMENT-SIGNATURE header.

Two-POST payment flow (same for every endpoint)

import json, httpx

def x402_call(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact scheme challenge with your Base wallet (EIP-3005),
    #    then re-send with PAYMENT-SIGNATURE header
    sig = signer.sign_challenge(challenge)
    r2 = httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig})
    return r2.json()

Any EIP-3005 signer works. Alternative: RAEN's Bearer-gated MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key, email verification), same tools over MCP if you prefer a client over raw HTTP.

SmolAgents tool wrappers

smolagents ≥ 1.0 — plain @tool decorators work with CodeAgent and ToolCallingAgent alike:

from smolagents import CodeAgent, tool, InferenceClientModel

@tool
def contract_analyze(text: str, focus: str = "") -> dict:
    """Analyze contract text for risky, one-sided, or unusual clauses.
    Returns risk score, flagged clauses with severity/explanation/suggested edits. $0.05/call."""
    focus_list = [f.strip() for f in focus.split(",") if f.strip()]
    return x402_call("https://contract-eye-x402.fly.dev/api/analyze-contract",
                     {"text": text, "focus": focus_list})

agent = CodeAgent(tools=[contract_analyze], model=InferenceClientModel())
agent.run("Analyze this lease for auto-renewal traps: ...")

Multi-agent pattern

from smolagents import CodeAgent, ToolCallingAgent, InferenceClientModel

# A router agent with the $0.50 dispatch tool + a specialist agent with
# the domain tools. Dispatch returns the exact downstream URL, body and
# price — the specialist executes it through the same x402_call.
router = ToolCallingAgent(tools=[dispatch], model=InferenceClientModel())
specialist = CodeAgent(tools=[contract_analyze, law_lookup], model=InferenceClientModel())
