You built an MCP server. Here's how to get paid for it.

Audience: developers publishing MCP servers (Anthropic registry, Smithery, mcp.so) whose tools generate real API costs they eat for free.

The pattern: x402 turns any HTTP endpoint into a paid endpoint using native HTTP 402. The client's agent pays in USDC on Base, on-demand, no subscription, no accounts. We run this in production on 12 live services (challenge → settle → telemetry, real on-chain settlement).

The 10-minute version

  1. Expose a plain JSON API route on your server's host (Fly, Vercel, anywhere).
  2. Return a 402 with an accepts block: scheme: "exact", network: "eip155:8453" (Base), payTo: <your wallet>, amount in USDC base units.
  3. Verify the payer's X-PAYMENT header against a facilitator, then serve the tool output.

Your MCP tool handler becomes a thin wrapper: forward the call to your paid route. Agents already speak x402 — the payment is invisible to the human.

Manifest your server

Publish /.well-known/x402.json so aggregators and agents discover your pricing:

{"version":"2.0.0","endpoints":{"/api/tool":{"method":"POST","accepts":{"scheme":"exact","price":"$0.05","network":"eip155:8453","payTo":"0xYOUR_WALLET"}}}}

What we learned deploying it 12 times

  • Pricing: $0.05–$0.10 per call is the working band. Zero-value challenges can't settle — use charge-and-rebate if you want a free tier.
  • Trust: publish a public settlement ledger. Bots generate 99% of challenge traffic; your first real payer is the milestone that matters.
  • Ops: Fly secrets don't refresh a running machine's env — a manifest fix isn't real until a live 402 decode shows your wallet.
