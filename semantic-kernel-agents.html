Paid API tools for Semantic Kernel agents (x402 · Base USDC)

Microsoft semantic-kernel agents and .NET / Python automations pay per call for real work — no API keys, no signups, no monthly plans. Every endpoint below accepts USDC on Base via the x402 HTTP-native payment protocol: a request without payment gets a 402 challenge; you sign the challenge (EIP-3009 transferWithAuthorization) with your wallet and re-send with a PAYMENT-SIGNATURE header.

Two-POST payment flow (same for every endpoint)

import json, httpx

def x402_call(url: str, body: dict, signer) -> dict:
    # 1) trigger the challenge
    r = httpx.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    challenge = json.loads(r.headers["payment-required"])  # contains accepts[]
    # 2) sign the exact scheme challenge with your Base wallet (EIP-3009),
    #    then re-send with PAYMENT-SIGNATURE header
    sig = signer.sign_challenge(challenge)
    r2 = httpx.post(url, json=body, headers={"PAYMENT-SIGNATURE": sig})
    return r2.json()

Any EIP-3009 signer works. Alternative: RAEN's Bearer-gated MCP gateway at https://raen-mcp-gateway.fly.dev/mcp — free dev key via POST /keys/request (30-day key, email verification), same tools over MCP if you prefer a client over raw HTTP. Semantic Kernel has first-class MCP support via McpStdioClientAdapter / McpHttpClientPlugin if you'd rather connect that way.

Semantic Kernel plugin (Python)

semantic-kernel ≥ 1.x — plain plugin class with @kernel_function methods, registered with add_plugin and callable through automatic function calling:

import asyncio
from semantic_kernel import Kernel
from semantic_kernel.functions import kernel_function
from semantic_kernel.connectors.ai.open_ai import OpenAIChatCompletion

from x402 import x402_call  # the two-POST helper above

class RaenPaidTools:
    """RAEN x402 paid endpoints as Semantic Kernel functions."""

    @kernel_function(description="Analyze contract text for risky, one-sided, or unusual clauses. $0.05/call.")
    async def contract_analyze(self, text: str, focus: str = "") -> dict:
        focus_list = [f.strip() for f in focus.split(",") if f.strip()]
        return x402_call("https://contract-eye-x402.fly.dev/api/analyze-contract",
                         {"text": text, "focus": focus_list})

    @kernel_function(description="Look up US consumer-law citations (FCRA/FDCPA/TILA/UDAP). $0.05/call.")
    async def law_lookup(self, topic: str, state: str = "") -> dict:
        return x402_call("https://royal-ruby-x402.fly.dev/api/law-lookup",
                         {"topic": topic, "state": state})

kernel = Kernel()
kernel.add_plugin(RaenPaidTools(), plugin_name="raen")
kernel.add_service(OpenAIChatCompletion(service_id="default", ai_model_id="gpt-4o-mini"))
# with function_choice_behavior="auto", the planner invokes the paid function
# only when the task needs it — each call settles $0.05 USDC on Base.

.NET shops: the same two-POST flow works with HttpClient and a KernelFunctionFactory-wrapped delegate, or expose the endpoints as a native plugin class implementing KernelFunction. The HTTP contract (402 challenge → PAYMENT-SIGNATURE re-send) is language-agnostic.
