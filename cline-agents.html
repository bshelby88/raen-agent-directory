Paid API tools for Cline (x402 · Base USDC)

Cline — the open-source autonomous coding agent for VS Code — speaks MCP natively, which makes it a natural host for the RAEN paid-tool catalog. Two payment paths: the RAEN MCP gateway added as a remote MCP server (Path 1, no wallet needed — the Bearer dev key is the billing rail), or the raw two-POST x402 flow executed from Cline's own terminal with your wallet (Path 2). Everything below accepts USDC on Base via the x402 HTTP-native payment protocol.

Path 1 (recommended, no wallet): RAEN MCP gateway as a remote MCP server

First get a free 30-day dev key (email-verified, self-serve):

curl -X POST https://raen-mcp-gateway.fly.dev/keys/request \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com"}'
# → check your inbox for the verification link + key

Then add the gateway in Cline: open the MCP Servers panel → Installed → Advanced Settings → add a remote server:

Name:    raen
URL:     https://raen-mcp-gateway.fly.dev/mcp
Headers: Authorization: Bearer ***

This lands in cline_mcp_settings.json under your Cline settings dir — keep the key out of any committed file; paste the Bearer value from your inbox and treat the settings file as a secret. Tools appear to Cline as raen__raen_law_lookup (FCRA/FDCPA statute citations), raen__raen_ticker_analysis, raen__raen_dispute_letter, raen__raen_image_generate, raen__raen_contract_analysis. The gateway's 402 paid gate makes the Bearer key the billing rail — Cline pays per MCP tool call without ever touching a wallet. Verify the handshake by asking Cline "list your raen tools".

Path 2 (wallet-native): the two-POST x402 flow from Cline's terminal

Cline executes bash and python in its VS Code terminal, so it can run the raw x402 flow directly — hand it cookbook recipe 02 and it writes the signer verbatim (~30 lines, web3.py):

POST https://royal-ruby-x402.fly.dev/api/law-lookup   (no payment header)
← 402 + payment-required header AND body (base64 JSON: amount, payTo, asset)
# sign USDC transferWithAuthorization (EIP-3009) for that exact amount
POST same URL + x-payment header (base64 signed JSON)
← 200 + result body + x-payment-response (settlement tx on Base)
Cline-specific spend guardrails: Cline's auto-approve can execute terminal commands without asking. Before enabling wallet-path payments, turn auto-approve OFF for terminal commands, or scope it tightly. Load the wallet key as an env var (export RAEN_WALLET_KEY=...) and never let Cline write a key into a file inside your repo. Put the budget rule in .clinerules (Cline reads it every task): e.g. "never sign an x402 challenge above $1.00 — ask me first". Interactive approval is the hard backstop.
