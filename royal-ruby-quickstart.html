royal-ruby Law-Lookup API quickstart

Who this is for: developers building credit-repair tools, dispute-letter generators, debt-collection compliance checks, or consumer-law chatbots who need accurate US statute citations — FCRA, FDCPA, TILA, and state UDAP statutes — returned as structured JSON with plain-English summaries, reporting timelines, and statutes of limitations.

Price: $0.05 USDC per call, settled on-chain via x402 on Base Mainnet. Your wallet's first call is free (charged then fully rebated — net $0).

1. Try the endpoint (free — decode the challenge)

curl -i -X POST https://royal-ruby-x402.fly.dev/api/law-lookup \
  -H 'Content-Type: application/json' \
  -d '{"topic":"credit dispute"}'

Without a payment header you get HTTP 402 and a base64 payment-required challenge. Decoded (verified live 2026-11-11): scheme: exact, network: eip155:8453, amount: 50000 ($0.05 USDC), payTo: 0x9b8a27e03ceba490953cda8ab1291c0e13baf72f, asset USDC 0x8335…2913. Challenge before payment means you can verify every price and destination yourself — nothing is hidden.

2. Pay with any x402 client

Use any x402-compatible HTTP client (the x402 fetch middleware, an agent framework integration, or raen-agent-kit templates for LangChain/LangGraph and CrewAI). The client signs a USDC transferWithAuthorization on Base, retries with the X-PAYMENT header, and receives the full result JSON. There is no account, no API key, no signup — the payment itself is the auth.

3. Response shape

A successful call returns statute records for the requested topic: statute name, citation, jurisdiction, a plain-English summary, credit-reporting timelines where applicable, and the statute of limitations. Free reference companion (36 plain-English statute pages, no payment at all): raen-law-pages.vercel.app — use the free pages to browse, the API to integrate.

Honest caveats: Information only — not legal advice. Summaries are plain-English restatements, not counsel. If you need a no-code option, the $49 Dispute Package bundles 3 letters + 12 citations + filing guide, and the MCP gateway exposes the same lookup as raen_law_lookup (quickstart).
