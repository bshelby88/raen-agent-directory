STEP 2 / 3 · Pay it — the one-liner (optional)

That challenge is the whole API contract: no account, no API key. Any x402 client signs the USDC exact transfer on Base and replays the request with the payment header. Grab the challenge with curl (returns in under a second):

curl -s -D - -o /dev/null -X POST https://dispatch-x402.fly.dev/dispatch \
  -H 'Content-Type: application/json' -d '{"intent":"create an escrow between two agents"}' \
  | grep -i payment-required

Prefer an agent-native CLI? npx agentcash discover https://dispatch-x402.fly.dev exists, but as of Nov 13 it hangs headless (no output for 90s+, even with deps cached) — set a timeout or use the curl above. Working client recipes: x402 cookbook recipes 01/02.
