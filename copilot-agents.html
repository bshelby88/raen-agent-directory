Paid API tools for GitHub Copilot / VS Code agent mode (x402 · Base USDC)

VS Code agent mode (GitHub Copilot) runs MCP servers defined in .vscode/mcp.json. The RAEN MCP gateway exposes 5 paid tools — US consumer-law citations, dispute letters, contract risk analysis, image generation, market/ticker analysis — as one Streamable-HTTP MCP server. Copilot's agent calls them whenever a task needs that work, and each call is pay-per-call USDC on Base via x402. No API keys, no subscription, no monthly plan: the payment is the authorization.

Step 1 — get a free dev key (email-verified, 30 days)

curl -X POST https://raen-mcp-gateway.fly.dev/keys/request \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com"}'

You get a verification link by email; verifying returns a 30-day Bearer key. Rate limit 3 keys/day/IP. The key funds nothing — it identifies you; payments happen per-call from your own wallet.

Step 2 — add the gateway to .vscode/mcp.json

{
  "servers": {
    "raen-paid-tools": {
      "type": "http",
      "url": "https://raen-mcp-gateway.fly.dev/mcp",
      "headers": {
        "Authorization": "Bearer <your-dev-key>"
      }
    }
  }
}

VS Code detects the config change and starts the server. Copilot agent mode then lists the 5 RAEN tools and can invoke them mid-task. Verify the server is alive: GET https://raen-mcp-gateway.fly.dev/health (200) and GET /.well-known/agent.json (the A2A agent card, 5 tools).

Step 3 — pay per call from your own wallet (raw HTTP, no gateway)

If you prefer no key at all, every fleet endpoint is directly callable with the two-POST x402 flow — a request without payment returns 402 with the challenge; you sign it (EIP-3009 transferWithAuthorization, USDC on Base) and re-send with the PAYMENT-SIGNATURE header:

import json, requests
from eth_account import Account   # any EIP-3009 USDC signer works

def x402_call(url, body, signer):
    r = requests.post(url, json=body)
    if r.status_code != 402:
        return r.json()
    # challenge is in the payment-required header AND the body (quote-fix deployed fleet-wide)
    challenge = r.json().get("accepts") or json.loads(r.headers["payment-required"])["accepts"][0]
    sig = sign_usdc_eip3009(signer, challenge)   # your wallet signs the transferWithAuthorization
    return requests.post(url, json=body,
                         headers={"PAYMENT-SIGNATURE": sig}).json()

The 402 body now carries the full quote (scheme, price, asset USDC, network eip155:8453, payTo) — fleet-wide quote-fix, verified live 2026-11-13 — so any body-parsing agent works without header plumbing. VS Code's built-in fetch/API testing in agent mode can drive the same flow.

Why this fits Copilot agent mode

  • MCP-native: agent mode consumes .vscode/mcp.json servers directly — one config block, no extension.
  • Per-call economics: Copilot sessions are intermittent; per-call USDC beats a monthly plan when you use a tool twice a week.
  • Free first call: new wallets get a charge-and-rebate first call (pay the challenge, get it rebated) — try the flow risk-free.
TRUTH-law caveats: payments are real USDC on Base — fund a wallet before paid calls; there is no free tier beyond the first-call rebate. The x-payer-address header (your wallet address) on the first call triggers the rebate. Prices can change; the live 402 challenge is always the source of truth for what a call costs right now. Law and dispute outputs are information, not legal advice. The gateway is RAEN-operated; the fleet's public sales ledger is at settlement-collector.fly.dev/ledger — see what other buyers actually settled before you pay.
