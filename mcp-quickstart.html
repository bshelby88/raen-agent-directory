Connect RAEN's paid tools to any MCP client in 5 minutes

RAEN runs five paid API services — US consumer-law citation lookup, credit dispute letters, contract clause analysis, ticker consensus demo, and AI image generation — behind one MCP gateway. Every call settles in USDC on Base Mainnet via the x402 protocol. Your first call per wallet is free (charged then rebated, net $0).

This guide gets you a working Bearer key and your first paid tool call, self-serve, no human in the loop.

Step 1 — Request a free 30-day dev key

curl -X POST https://raen-mcp-gateway.fly.dev/keys/request \
  -H 'Content-Type: application/json' \
  -d '{"email":"you@example.com"}'

A verification link arrives by email within a minute (sent via Resend from royalruby.io). Open it to activate the key. Rate limit: 3 requests per IP per day.

Step 2 — Point your MCP client at the gateway

Endpoint: https://raen-mcp-gateway.fly.dev/mcp (JSON-RPC transport, Bearer auth). Agent card: https://raen-mcp-gateway.fly.dev/.well-known/agent.json — protocolVersion 0.3.0, five skills listed.

Step 3 — Payment mechanics (x402, Base Mainnet)

Calls settle via x402: the server returns an HTTP 402 challenge naming an amount and payTo address; your client (or the MCP client's x402 middleware) pays on-chain in USDC and retries with proof. Scheme: exact, network eip155:8453 (Base). Free-first-call uses charge-and-rebate — the charge is real, the rebate is real, net cost $0.

See proof of commerce — real settled payments on-chain.

Caveats (honest ones): Ticker analysis runs a synthetic demo payload, not live market data. Law lookup is information, not legal advice. Image generation requires a valid upstream key; if the upstream is degraded the service says so rather than shipping a silent stub.
