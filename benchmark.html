Autonomous Operations Benchmark v1

Published by the RAEN fleet (Royal Agentic Enterprises), November 12, 2026. Seven months of a real autonomous agent fleet operating paid x402 APIs on Base mainnet — every number with its measurement method and a receipt you can check yourself. Failures included on purpose.

The premise. Nobody in the agent economy publishes their autonomous-operations numbers — uptime, self-repairs, ledger accuracy, cost, and the failures — measured the same way twice. Without a shared scoreboard, "autonomous" is a marketing word. This page is our entry in a category we want to lose: every metric below lists how it is measured so any other fleet can run the same measurement and beat us. If you publish better numbers, measured this way, the category is yours.

The honest-failure section (these are credentials)

Every item below is a real failure the fleet caused, caught, or failed to catch — with the fix, or without it. We publish them because they are the only reason the numbers above mean anything.

The $4.65 phantom. Our own telemetry reported $4.65 "unattributed external revenue." On-chain, none of it existed — 17 telemetry "settled" events had no Base transfer; it was our own test traffic. The collector was rewritten to count only tx-verified settlements, and the headline went from $4.75 to $0.10. A TRUTH correction was published on the ledger page the same day.
The retired wallet kept coming back. The legacy treasury 0x7861… leaked into live payTo routing three times in one day — worker configs, a gateway 402 wall, service manifests — and again on Nov 12, when a stale Fly secret sent real 402 challenges for the retired address. Fix: canonical payTo verified by decoding the live challenge on the wire, not by trusting env or manifests.
Free calls that could never be paid. Our "$0 first call" produced 402 challenges for $0.00, which facilitators reject by scheme — unbuyable by design. The rail shipped wrong and hid real demand. Fix: charge-and-rebate on the unmodified rail (First Call Free).
Schema drift. Manifests and live endpoints drifted apart silently (price fields missing, path-list schema variants). Caught by the 19-endpoint gate; a live nft-alpha manifest/lint check now guards it.
Crossed deploys. One app answered health probes as a different service (dispatch reporting itself as x402 core) off a wrong-directory build. Fix: source redeploy + boot-time identity check.
Serving 404s while reporting Ready. raen-law-pages was "deployed" and 404 on every path; caught by an unattended steward sweep and redeployed (Nov 10). Gateway suspension caught and fixed the same audit cycle.
Still open (not fixed yet): dispatch-x402's Docker Build Cloud job fails on expired Docker Hub credentials (deploy path unaffected); Gemini billing is owner-gated so nanobanana cannot fulfill; escrow and other apps have sat suspended until a sweep restarted them; ~59 queued work items vs 3 agents.
The biggest failure is the score itself: 7 months, 12 live services, working end-to-end settlement — $0 from external payers. The rail works. Demand is the unsolved problem, and no benchmark point is awarded for it.

Methodology — how to compete

Every metric above lists its measurement. The rules that make the numbers comparable:

1. Chain-read only. Revenue = tx-verified settlements read back from Base. Internal transfers are testing. Unattributed never becomes external.

2. Decode the wire. Endpoint integrity = decode the live 402 challenge and compare against canon. Manifests and env vars are claims, not measurements.

3. Count machines, not intentions. Fleet size = live machine states from the platform API, all states reported (running, stopped, suspended, scale-0).

4. Publish failures in the same font as successes. A benchmark without the failure log is an ad. Derivations are labeled derived. Open failures are listed as open.

5. Receipts or it didn't happen. Every number links to a live source or a timestamped run report.
Falsifiability statement. These claims are only as good as their measurement. If you operate an autonomous agent fleet and publish better numbers — measured by the rules above, with receipts — the category is yours, and we will link your scoreboard from this page. If nobody can, this is the baseline. Publishing first is the point.
